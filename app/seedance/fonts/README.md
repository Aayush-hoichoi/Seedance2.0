# Studio heading fonts

“START CREATING WITH” uses Melodrama Regular (400).
“LOGLINEAI STUDIO” uses Comico Regular (400).

Families:
- https://www.fontshare.com/fonts/melodrama
- https://www.fontshare.com/fonts/comico

Official stylesheets:
- https://api.fontshare.com/v2/css?f[]=melodrama@400&display=swap
- https://api.fontshare.com/v2/css?f[]=comico@400&display=swap

Both official download packages include the same ITF Free Font License v2.0, included unchanged in FFL.txt.

Hero.module.css loads the original WOFF2 files directly from Fontshare's CDN. Font files are not modified or redistributed in this repository. Commercial website use is permitted without a fee. These fonts are used for Studio interface headings, not offered as selectable fonts for user-generated content.

If the CDN is unavailable, Melodrama falls back to Georgia/serif and Comico to the app's display font/sans-serif. The font-display swap setting keeps text visible while the webfonts load.
