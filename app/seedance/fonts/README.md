# Studio heading font

“START CREATING WITH” uses Melodrama Regular (400) from Fontshare.

Family: https://www.fontshare.com/fonts/melodrama
Official stylesheet: https://api.fontshare.com/v2/css?f[]=melodrama@400&display=swap
License: ITF Free Font License v2.0, included unchanged in FFL.txt from the official download package.

Hero.module.css loads the original WOFF2 directly from Fontshare's CDN. The font file is not modified or redistributed in this repository. Commercial website use is permitted without a fee. The font is used for the Studio interface heading, not offered as a selectable font for user-generated content.

If the CDN is unavailable, the heading falls back to Georgia/serif. The font-display swap setting keeps text visible while the webfont loads.
